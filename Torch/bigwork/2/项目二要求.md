# 大作业：基于胸部 X 光片的肺炎自动识别与分类

## 项目背景与数据集说明

肺炎是全球范围内导致死亡的主要原因之一，通过胸部 X 光片进行早期、准确的诊断对于临床治疗至关重要。本项目旨在利用深度学习模型，构建一套自动识别肺炎影像的分类系统。

- 目标：区分正常胸部 X 光影像（标签 0）与患有肺炎的 X 光影像（标签 1）。辅助放射科医生提高筛查效率，降低漏诊率。
- 两类数据位于数据集文件夹中的0和1两个文件夹中存放

## 2. 项目方案

- 尺寸归一化：两个数据集中各个图片的尺寸都有细微区别，因此需要将所有图片归一化为同一尺寸。
- 数据清洗与筛选：剔除标注模糊的样本。
- 类别均衡：确保各集合中肺炎与正常样本的分布相对均衡，或在训练时采取过采样/欠采样策略。
- 数据划分：按照合适的比例划分训练集、测试集、验证集(可选)，分别用于训练模型、评估模型和调参。
- 模型搭建：选择合适的分类特征提取器，推荐LeNet-5/ResNet/ DenseNet/SENet，设置合适的层数与超参数，搭建完整的端到端模型。
- 模型优化：选择合适的损失函数和优化方法，尝试使用在模型优化部分提到的优化方法（正则化、BN、Dropout等）来尽可能提升模型效果。
- 模型评估：完成模型的训练过程，使用验证集完成超参数调整(可选)，计算模型在测试集上的准确率、召回率、精确度和F1值，画出ROC曲线并计算AUC，损失下降曲线、准确率提升曲线以及混淆矩阵图。
- 模型持久化：最后保存模型与参数。
